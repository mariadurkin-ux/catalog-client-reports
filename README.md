# Catalog Client Reports

Hosted, client-facing TikTok music detection reports. Each file is a
self-contained snapshot (no separate CSVs, no login) generated by the
`music_detection_api` notebook and pushed here under a random filename
-- deliberately not named after the client, since this repo is public.

Served via GitHub Pages at:
https://mariadurkin-ux.github.io/catalog-client-reports/
